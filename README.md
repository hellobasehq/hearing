# ヒアリングページ

お客様にURLを送るだけで、ログインなしでスマホから回答してもらえるページと、決まったことを一覧で見せるページ。Google Apps Script のWebアプリ（宮田さんのアカウントで実行）。

## URL
- お客様に送るURL：`https://hellobasehq.github.io/hearing/?k=<コード>`（決定事項まとめは `#summary` を付けるか、ページ上のタブで切り替え）
- 画面は GitHub Pages（このリポジトリの `docs/`）。データは Apps Script のWebアプリに `?p=data` で取りに行き、回答は POST で送る
- 画面をGoogleの外に置いているのは、ブラウザが複数のGoogleアカウントにログインしていると Apps Script の画面が開けない不具合を避けるため
- Apps Script 側の画面（`<WEBAPP_URL>?k=<コード>&p=hearing`）も残してあるが、お客様には使わない
- 「c」「sid」は Apps Script の予約語なので、コードは「k」で渡す

コードはお客様ごとに推測されにくい文字列を自動で振る。台帳の「有効」を FALSE にするとそのお客様のページは開けなくなる。

## スプシ
- **ヒアリング台帳**（1冊）：顧客タブにコード・お客様名・スプシ・URLを記録
- **ヒアリング_お客様名**（お客様ごとに1冊）
  - 項目：質問・案・説明・表示順。種類は info / single / multi / date / color / text / textarea
  - 回答：送信のたびに追記（消さない）
  - 決定事項：項目ごとの最新の回答と状態。**HBが確認して「決定」にした項目だけがまとめページの「決まっていること」に出る**。決定内容の欄に書けば、その文章が優先される
  - 設定：ページタイトル・宛名・案内文

## 新しいお客様を足す
1. エディタで `createCustomer('お客様名', 'ローマ字')` を実行（ログにURLが出る）
2. できたスプシの「項目」タブに質問を入れる
3. `syncDecisionRows('<スプシID>')` を実行して決定事項タブの行をそろえる
4. ヒアリングのURLをお客様に送る

## スクリプトプロパティ
- `LEDGER_ID`：setup() が自動で入れる
- `WEBAPP_URL`：デプロイしたURL（/exec まで）
- `SLACK_WEBHOOK_URL`：回答時の通知先（任意。宮田さんが設定）

## 注意
- URLを知っている人は誰でも開けて送信できる。個人情報や金額の詳細は載せない
- 回答の上書きは「回答」タブに履歴として残る
